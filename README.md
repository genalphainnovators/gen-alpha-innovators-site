# Gen Alpha Innovators

Website for Gen Alpha Innovators (STEM, robotics and coding for Classes 1-10).
Static HTML/CSS, served by GitHub Pages from `main`. The home page is `index.html`; course detail pages live in their own directories (for example, `tinkercad/index.html`). Shared styles are in `styles.css`.

Push changes to `main` to publish them.

Live: https://sasi-vadde.github.io/gen-alpha-innovators/
